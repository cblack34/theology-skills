Open these only when the reading is disputed, a quotation is in play, or the user asks for the form.

|---|---|---|

| OT in Greek | Rahlfs 1935 LXX with morphology | https://github.com/eliranwong/LXX-Rahlfs-1935 |
| Pseudepigrapha | Online Critical Pseudepigrapha | https://github.com/OnlineCriticalPseudepigrapha/Online-Critical-Pseudepigrapha |

## When to compare

- NT citation or clear allusion: compare MT and LXX. State which the NT follows.
- No citation: do not import an LXX reading into a Hebrew clause.
- Pseudepigrapha: only after an echo is claimed. Name the work and section. A thematic parallel is not dependence.

## Lookup

Prefer the file in the repo over a paraphrase of the form. If the file cannot be opened, say the form was not checked.
